تشغيل سيرفر الاختبار المحلي:

1. افتح PowerShell في المجلد Downloads أو حيث وضعت الملفات.
2. تأكد من وجود `server.js` و `index.html.html` في نفس المجلد.
3. شغّل السيرفر بالتالي:

```powershell
node server.js
```

4. افتح الملف `index.html.html` في المتصفح (مثلاً بالسحب والإفلات أو فتح الملف).
5. ادخل البريد والمبلغ ثم اضغط "تحويل الآن" — سترى رسالة نجاح محاكاة من السيرفر.

ملاحظة: إذا أردت استضافة الصفحة عبر http بدل فتح الملف مباشرة، يمكنك استخدام أي سيرفر بسيط (مثلاً `npx http-server .` بعد تثبيت) حتى تتجنب بعض قيود المتصفح على `file://` origins.# شغّل السيرفر التجريبي (Node)
cd C:\Users\AHMED\Downloads
node server.js

# أو سيرفر ثابت سريع (إذا الصفحة فقط ملفات HTML/CSS/JS)
npx http-server . -p 8080
# أو (بايثون)
python -m http.server 8000
